# Roteiro de demonstração

1. Execute a aplicação conforme o README e abra http://127.0.0.1:8002.
2. Apresente o problema, a entrada e o resultado de demonstração.
3. Mostre os dados sintéticos em `data/` e explique por que não representam impacto real.
4. Altere uma entrada para provocar um caso sem resultado, um alerta ou uma validação.
5. Execute `python -m pytest -q` e `python -m app.evaluate`.
6. Explique a referência de comparação, as limitações do conjunto e o que seria necessário para validar com usuários reais.

Grave uma demonstração curta somente depois de compreender os módulos em `app/`. Não apresente o código como experiência profissional em produção.
